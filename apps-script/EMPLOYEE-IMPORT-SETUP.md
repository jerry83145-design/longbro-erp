# 員工新增與匯入的 Google 串接更新

網站新增員工和 Excel / CSV 匯入需要新版 Apps Script。只推送 GitHub Pages 不會更新 Google 的串接程式。

1. 開啟目前 ERP 使用的 Apps Script 專案。
2. 將本資料夾 `Code.gs` 的員工資料讀取／更新函式與 `payrollMasterFields` 更新至線上專案。保留線上既有的 CONFIG 設定，不要變更密鑰或其他串接設定。
3. 點選「部署」→「管理部署」→ 目前網頁應用程式的編輯圖示。
4. 版本選「新版本」，按「部署」。使用既有部署，不需改網站網址。
5. 網站重新整理後，在薪資頁選擇未發薪月份，使用「新增員工」或「匯入員工」。

同步會先檢查 Google 串接版本；未升級時會保留預覽內容並顯示提示，不會宣稱同步成功。

匯入使用第一個工作表，欄名請依下載範本。到職日及眷屬加保日期使用 YYYY-MM-DD；投保薪資須填實際核定資料。確認同步時若只有部分完成，會顯示已完成筆數，可在同一預覽重試。

驗收：新增員工出現在 Google 員工資料表及適用月份的薪資表；既有員工須勾選更新才能匯入；已發薪月份禁止建檔；原有表格其他欄位保留。
