# 下載整理工具說明

這個工具會監看 Windows 的下載資料夾：

```text
C:\Users\Ray\Downloads
```

新下載的 ERP 報表、備份、銀行明細、進銷存、發票與收據，會依規則搬到：

```text
C:\Users\Ray\Documents\會計
```

## 使用方式

### 1. 平常自動整理

開機後會自動啟動：

```text
C:\Users\Ray\Documents\會計\工具\start-download-organizer.bat
```

它只會整理「工具啟動後的新下載檔案」。

### 2. 整理目前已下載的舊檔

如果檔案已經在 Downloads 裡，請點這個：

```text
C:\Users\Ray\Documents\會計\工具\scan-downloads-now.bat
```

它會掃描目前 Downloads 裡的檔案，只搬移確定能分類的檔案。
不確定的檔案會先跳過並寫入紀錄，不會一直跳視窗卡住。

## 工具檔名中英文對照

| 檔名 | 中文用途 |
| --- | --- |
| `start-download-organizer.bat` | 啟動下載自動整理工具 |
| `restart-download-organizer.bat` | 重啟下載自動整理工具，讓最新規則生效 |
| `scan-downloads-now.bat` | 手動整理目前 Downloads 裡的舊檔 |
| `debug-start-download-organizer.bat` | 除錯啟動工具，會顯示黑色視窗 |
| `download-organizer.ps1` | 主要整理程式 |
| `restart-download-organizer.ps1` | 重啟整理工具的控制程式 |
| `download-rules.json` | 分類規則設定 |
| `下載整理工具說明.md` | 本說明文件 |

## 目前分類

| 分類 | 用途 |
| --- | --- |
| `A_ERP備份` | 隆博 ERP 匯出的資料備份 |
| `B_正式報表` | 內帳報表、日報、週報、月報、損益、資產負債、現金流 |
| `C_匯入原始檔` | Excel、CSV 等原始匯入資料 |
| `D_憑證收據` | 發票、收據、三聯式、二聯式、憑證照片或 PDF |
| `E_行政人員同步` | 行政清單、處理清單、Drive Sync 檔 |
| `F_銀行與金流` | 銀行明細、對帳單、信用卡、金流資料 |
| `G_進銷存資料` | 庫存、卡盒、卡片、包材、入庫、出庫資料 |
| `Z_待確認` | 不確定分類的檔案 |

## 重要邏輯

- 從 ERP 網站下載的檔案會自動整理。
- 修改規則後，請點 `restart-download-organizer.bat`，讓背景工具重新讀取最新規則。
- Google Drive 下載的發票可能沒有 ERP 來源資訊，所以會依檔名判斷。
- 檔名有「三聯、二聯、發票、收據、憑證、統編、發票號碼」會歸到 `D_憑證收據`。
- 已經存在 Downloads 的檔案，不會被背景工具自動回頭整理；請使用 `scan-downloads-now.bat`。
- 手動整理目前 Downloads 時，只會搬確定分類的檔案；不確定的會留在 Downloads。
- 同名檔案不會覆蓋，會自動加 `_v2`、`_v3`。
